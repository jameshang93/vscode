# Personal VS Code development workflow

How I use this fork for learning and small personal patches.

## Before changing code

1. Skim the relevant package / area README
2. Note the exact behavior I want to change
3. Prefer the smallest possible patch surface

## Local verification

- Launch a desktop / web build path documented upstream when needed
- Smoke-test only the feature I touched
- Keep reproduction steps in the PR description
