# Personal VS Code editor defaults

Personal editor preferences tracked against this fork.

## Editor preferences

- Format on save for supported languages
- Trim trailing whitespace on save
- Keep rulers / wrap settings consistent across machines
- Prefer workspace settings over one-off UI toggles

## Extension shortlist

- Language support I actually use week to week
- Git helpers that reduce friction without noise
- One theme I stick with to avoid churn

## Sync checklist

1. Export / document key bindings I rely on
2. Keep a minimal settings snippet for new machines
3. Revisit extensions quarterly and remove unused ones
